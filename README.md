# Validate AI CIC

A simple public website for Validate AI CIC, built with Next.js, TypeScript and Tailwind CSS.

## Content

Copy is drawn from the Validate AI Website Master Source Pack. The site presents Validate AI as an independent Community Interest Company working across Responsible AI, AI assurance, AI risk, professionalisation and cross-sector collaboration.

Event photography is not yet available. Placeholder images are labelled as such.

## Pages

- `/` Home
- `/about` About
- `/ai-assurance` AI Assurance
- `/ai-risk-perspectives` AI Risk Perspectives
- `/our-work-impact` Our Work & Impact
- `/insights` Insights
- `/get-involved` Get Involved

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
